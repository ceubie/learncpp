Chapter 0 gives context: what C++ is, how programs work, and what software you need. Chapter 1 is a broad, shallow overview so you can start writing simple programs. Later chapters go deeper.

These tutorials cover C++ and the surrounding skills textbooks often skip: style, common pitfalls, debugging, testing, and what not to do.

How to study
- Type examples by hand. Think about each line. You will learn common mistakes and the diagnostic messages they produce.
- Fix your own bugs before asking for help. Learn a debugger when the course covers it.
- Experiment. Change values, add behavior, try to break the program.
- Spend real time on quizzes. Looking at the answer is fine if you are stuck — understand it before moving on.
- Write short programs of your own. That is what sticks.

If you get stuck: comments, the next lesson or two, a search, then a Q&A site. Skipping and coming back later is allowed. Tired or unhappy programmers make more mistakes; debugging usually takes longer than writing the code correctly in the first place.
