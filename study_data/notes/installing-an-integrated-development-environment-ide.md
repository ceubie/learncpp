An IDE is software that makes it easier to write, build, and debug programs. Typical pieces: load/save files, a code editor (line numbers, highlighting, completion), a basic build system, an integrated debugger, and plugins (e.g. version control). Some IDEs install a compiler/linker for you; others let you plug one in.

Use a compiler that supports at least C++17. Do not use anything that cannot do C++11. Newest compiler is preferred.

Course recommendations (not memorizing install steps):
- Windows: Visual Studio Community, workload “Desktop development with C++”
- Linux (or Windows targeting Linux): Code::Blocks
- VS Code: fine for experienced users, a poor first C++ IDE — configuration is the hard part
- Web compilers (Wandbox, Godbolt, TutorialsPoint) are okay for dabbling, not for real debugging or multi-file work
- Avoid: Turbo C++, Visual Studio for Mac, Dev C++

Command-line compilers work, but beginners are better off with an IDE that works out of the box.
